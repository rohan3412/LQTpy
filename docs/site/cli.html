Command line

usage: lqtpy [-h] [--version] [--config CONFIG] COMMAND ...

Lesion morphometry, atlas overlap, quality checks and plain-language
descriptions, with self-contained HTML reports.

positional arguments:
  COMMAND
    single         Analyse one lesion and write a report.
    group          Analyse a group of lesions.
    describe       Print the plain-language description of a lesion.
    qc             Quality flags for a lesion, or a page for a whole folder.
    clean          Remove image-edge artefacts and specks into a new mask
                   (opt-in).
    repair         Interpolate sparse-slice gaps into a new mask (opt-in).
    warp           Warp a native-space mask to MNI.
    rerun          Repeat the analysis recorded in a report.
    watch          Rebuild a group report whenever masks are added or changed.
    serve          Upload page: colleagues get a report without Python.
    fetch          Download an optional atlas.
    new-plugin     Write a starter package for an extra measure.
    config         Show the settings file in use and its values.
    cache          Show (or clear) the template-map cache.

options:
  -h, --help       show this help message and exit
  --version        show program's version number and exit
  --config CONFIG  Settings file to use instead of the lqtpy.toml search.

Settings file: lqtpy.toml (see `lqtpy config`). Docs: README.md.

lqtpy single

usage: lqtpy single [-h] [--atlas ATLAS] [--out OUT] [--threshold THRESHOLD]
                    [--profile {stroke,small_vessel,tumour,research}]
                    [--extras EXTRAS] [--no-tracts] [--no-disconnection]
                    [--no-qc] [--no-describe] [--no-viewer]
                    [--anonymise [KEY_FILE]] [--quiet] [--pdf]
                    [--expected-side {left,right}] [--native NATIVE]
                    [--transform TRANSFORM]
                    lesion

positional arguments:
  lesion                Lesion file (.nii, .nii.gz, .mgz, .nrrd, .dcm)

options:
  -h, --help            show this help message and exit
  --atlas ATLAS, -a ATLAS
                        Atlas to use (repeatable): aal, schaefer, dk, jhu,
                        arterial. Default: aal, schaefer, dk, jhu, arterial.
  --out OUT, -o OUT     Output folder. Default: lqtpy_output/<name>.
  --threshold THRESHOLD, -t THRESHOLD
                        A voxel is lesion when its value is greater than this
                        (default 0.5).
  --profile {stroke,small_vessel,tumour,research}
                        Description style (default: stroke).
  --extras EXTRAS       Extra measures: "none" (default), "all", or a comma
                        list, e.g. "shape".
  --no-tracts           Skip white-matter tract overlap.
  --no-disconnection    Skip streamline disconnection even if an index is
                        installed.
  --no-qc               Skip mask quality checks.
  --no-describe         Skip the written description.
  --no-viewer           Leave out the slice viewer (smaller report).
  --anonymise [KEY_FILE], --anonymize [KEY_FILE]
                        Write IDs instead of file names everywhere; the
                        private key file maps them back (default
                        <out>/anonymisation_key.csv).
  --quiet, -q           Print only the report path.
  --pdf                 Also save the report as PDF (needs
                        Edge/Chrome/Chromium).
  --expected-side {left,right}
                        Flag the lesion if most of it is on the other side.
  --native NATIVE       The same lesion as a native-space mask: drawing checks
                        (gaps, single slice, outline) run on it.
  --transform TRANSFORM
                        LESION is a native-space mask: warp it to MNI with
                        this 4x4 matrix (text file, native mm -> MNI mm) or
                        deformation field, then analyse.

lqtpy group

usage: lqtpy group [-h] [--atlas ATLAS] [--out OUT] [--threshold THRESHOLD]
                   [--profile {stroke,small_vessel,tumour,research}]
                   [--extras EXTRAS] [--no-tracts] [--no-disconnection]
                   [--no-qc] [--no-describe] [--no-viewer]
                   [--anonymise [KEY_FILE]] [--quiet] [--pdf] [--pdf-bundle]
                   [--no-subject-reports] [--metadata METADATA]
                   [--subject-column SUBJECT_COLUMN] [--group-by GROUP_BY]
                   [--compare COLUMN [A B] [COLUMN [A B] ...]]
                   [--side-column SIDE_COLUMN] [--jobs JOBS] [--incremental]
                   lesions [lesions ...]

positional arguments:
  lesions               Lesion files, or one folder of lesions.

options:
  -h, --help            show this help message and exit
  --atlas ATLAS, -a ATLAS
                        Atlas to use (repeatable): aal, schaefer, dk, jhu,
                        arterial. Default: aal, schaefer, dk, jhu, arterial.
  --out OUT, -o OUT     Output folder. Default: lqtpy_output/<name>.
  --threshold THRESHOLD, -t THRESHOLD
                        A voxel is lesion when its value is greater than this
                        (default 0.5).
  --profile {stroke,small_vessel,tumour,research}
                        Description style (default: stroke).
  --extras EXTRAS       Extra measures: "none" (default), "all", or a comma
                        list, e.g. "shape".
  --no-tracts           Skip white-matter tract overlap.
  --no-disconnection    Skip streamline disconnection even if an index is
                        installed.
  --no-qc               Skip mask quality checks.
  --no-describe         Skip the written description.
  --no-viewer           Leave out the slice viewer (smaller report).
  --anonymise [KEY_FILE], --anonymize [KEY_FILE]
                        Write IDs instead of file names everywhere; the
                        private key file maps them back (default
                        <out>/anonymisation_key.csv).
  --quiet, -q           Print only the report path.
  --pdf                 Also save the report as PDF (needs
                        Edge/Chrome/Chromium).
  --pdf-bundle          PDFs of the group and every subject, merged into one
                        with bookmarks (the merge needs pypdf).
  --no-subject-reports  Don't write one report per subject.
  --metadata METADATA, -m METADATA
                        CSV/TSV with one row per subject (age, condition,
                        side, scores).
  --subject-column SUBJECT_COLUMN
                        Metadata column naming the subject.
  --group-by GROUP_BY   Metadata column to summarise the cohort by.
  --compare COLUMN [A B] [COLUMN [A B] ...]
                        Compare two groups: a metadata column with two values,
                        or COLUMN A B.
  --side-column SIDE_COLUMN
                        Metadata column with the lesion (or symptom) side for
                        the flip check; "auto" finds one, "none" turns it off.
  --jobs JOBS, -j JOBS  Worker processes (-1: one per CPU). Default 1.
  --incremental         Reuse results from an earlier run into the same folder
                        for unchanged files.

Settings file

``lqtpy.toml``: default settings for the command line.

Looked up in this order (the first file found wins; ``--config PATH``
overrides the search):

1. ``./lqtpy.toml`` (the current folder)
2. ``LQTPY_CONFIG`` (environment variable)
3. the user config folder: ``%APPDATA%\lqtpy\lqtpy.toml`` on Windows,
   ``~/.config/lqtpy/lqtpy.toml`` elsewhere

Example::

    [defaults]
    atlases = ["aal", "dk", "arterial"]
    profile = "stroke"          # stroke | small_vessel | tumour | research
    extras = "none"             # none | all | "shape,fractal"
    out_dir = "D:/lesion_reports"
    threshold = 0.5
    jobs = 4                    # group runs: worker processes
    pdf = false
    anonymise = false
    viewer = true

Command-line options always win over the file. The Python API ignores the
file (explicit arguments only), so scripts behave the same everywhere.
