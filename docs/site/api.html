lqtpy

LQTpy - Lesion Quantification Toolkit (lean rewrite).

analyze_single(lesion=None, atlases=None, out_dir=None, *legacy, lesion_path=None, threshold=0.5, tracts=True, write=True, plots=False, verbose=False, frame=None, qc=True, describe=True, profile='stroke', extras=None, disconnection='auto', expected_side=None, report_style=None, pdf=False, native=None, transform=None, anonymise=False, viewer=True)

Analyse one lesion; return a result dict and (optionally) write CSV/JSON tables (``write=True``) and a self-contained HTML report (``write=True`` and ``plots=True``). ``lesion`` accepts anything :func:`lqtpy.prepare` does (``lesion_path=`` is the old name). Core modules always run unless turned off (``qc``, ``describe``, ``tracts``, ``disconnection`` -- the latter runs automatically when an index is installed). ``extras`` selects extra measures: ``None`` (core only, the default everywhere), ``"all"``, or a list of names from :func:`lqtpy.registry.list_measures`. ``profile`` picks the description style (stroke / small_vessel / tumour / research). ``result["manifest"]`` records what ran and what didn't, and the input's checksum (``manifest["run"]`` is the full run record). Native space (:mod:`lqtpy.native`): ``native=`` a native-space mask runs the drawing checks there; ``transform=`` treats ``lesion`` as a native mask, warps it to MNI with that transform and does the same. ``anonymise=True`` (or a key-file path) writes an ID instead of the file name everywhere (:mod:`lqtpy.anonymise`). ``pdf=True`` (with ``write`` and ``plots``) also saves the report as PDF. ``viewer=False`` leaves out the scroll-through slice viewer (smaller file). Tables are records by default; ``frame="pandas"`` returns DataFrames. Arguments after ``out_dir`` are keyword-only (positional use is deprecated).

analyze_group(inputs=None, atlases=None, out_dir=None, *legacy, threshold=0.5, tracts=True, write=True, plots=False, verbose=False, frame=None, qc=True, describe=True, profile='stroke', extras=None, disconnection='auto', subject_reports=True, report_style=None, pdf=False, metadata=None, subject_column=None, group_by=None, compare=None, side_column='auto', n_jobs=1, anonymise=False, incremental=False, duplicates=True, outliers=True, viewer=True)

Analyse a group of lesions; return a result dict and (optionally) write group CSVs, a group HTML report (``plots=True``) and -- with ``subject_reports=True`` -- one full report per subject, linked from the group report. ``inputs``: a directory, a single lesion file, or a list of lesion sources or ``(name, source)`` pairs. Group tables report, per region, how many subjects are affected, the **cohort** mean (unaffected subjects count as 0), the mean over affected subjects, and the max. Cohort options: ``metadata`` CSV/TSV path, list of dicts, dict or DataFrame, one row per subject (:mod:`lqtpy.metadata`); joined into the subject table and CSV. ``subject_column`` names its subject column. ``group_by`` a metadata column to summarise the cohort by. ``compare`` a metadata column with two values (or ``(column, a, b)``): region-by-region comparison of the two groups (:func:`lqtpy.cohort.compare`) with side-by-side overlap maps. ``side_column`` metadata column giving the lesion side (or the symptom side); mismatches get a ``side_mismatch`` flag. ``"auto"`` finds one by name, ``None`` turns it off. ``duplicates`` flag identical / near-identical masks. ``outliers`` flag subjects far from the group (10+ subjects). ``n_jobs`` worker processes (``-1``: one per CPU). On Windows, call from under ``if __name__ == "__main__":``. ``incremental`` reuse cached per-subject results from a previous run into the same ``out_dir`` when the file and settings are unchanged. ``anonymise`` IDs instead of names everywhere; ``True`` or a key-file path (:mod:`lqtpy.anonymise`). ``pdf`` ``True``: the group report as PDF; ``"bundle"``: also every subject's PDF and, with ``pypdf`` installed, one merged PDF with bookmarks. Arguments after ``out_dir`` are keyword-only (positional use is deprecated).

describe(lesion, *, profile: 'str' = 'stroke', atlas: 'str' = 'dk', threshold: 'float' = 0.5, qc_flags=None, shape: 'bool' = False, networks: 'bool' = True, white_matter: "'str | None'" = 'jhu', territories: "'str | None'" = 'arterial', tissue: 'bool' = True, border_zones: 'bool' = True, key_structures: 'bool' = True, homologue: 'bool' = True) -> 'Description'

A plain-language description of a lesion. ``profile``: ``stroke`` (default), ``small_vessel``, ``tumour`` or ``research`` -- see the module docstring. ``shape=True`` adds shape descriptors (extra tier); ``tissue=False`` drops the tissue composition and location classes. Returns a :class:`Description` whose ``text`` is ready to show and whose ``facts`` hold every number behind it.

prepare(lesion, threshold: 'float' = 0.5, *, name: "'str | None'" = None) -> 'PreparedLesion'

Load, validate and binarize a lesion once. ``lesion`` is anything :func:`lqtpy.io.as_lesion_image` accepts, or an existing :class:`PreparedLesion` (returned unchanged; its own threshold stands). A voxel is lesion when its value is strictly greater than ``threshold``. NaN and inf voxels count as 0 and are reported in ``n_nonfinite``. Raises :class:`~lqtpy.errors.InvalidLesionError` for an empty mask.

lesion_stats(lesion, *, threshold: 'float' = 0.5) -> 'dict'

Morphometry for one lesion. Voxel count, volume in mm^3, and every other measure :func:`lqtpy.morphometry.compute_morphometry` computes (center of mass, bounding box, connected components, laterality...).

atlas_overlap(lesion, atlas_key: 'str', *, threshold: 'float' = 0.5) -> "'list[dict]'"

Per-region atlas overlap ("parcel damage") records for one lesion. ``atlas_key`` is anything :func:`lqtpy.atlases.list_atlases` lists (built-in or host-registered via :func:`lqtpy.atlases.register_atlas`/:func:`lqtpy.atlases.atlas_from_arrays`). Raises :class:`~lqtpy.errors.UnknownAtlasError` for an unregistered key.

atlas_coverage(lesion, atlas_key: 'str', *, threshold: 'float' = 0.5) -> 'dict'

How much of the lesion ``atlas_key`` can describe: labelled vs unlabelled lesion voxels on the atlas grid, and lesion voxels outside the atlas's field of view. See :func:`lqtpy.overlap.coverage`. Region rows' ``PercentOfLesion`` plus ``PercentUnlabelled`` add up to 100.

lobe_overlap(lesion, atlas_key: 'str', *, threshold: 'float' = 0.5) -> "'list[dict]'"

Lobe-level rollup records for one lesion, one row per anatomical lobe. Unlike :func:`network_rollup_for` (which groups by the atlas's ``Group`` field -- hemisphere for ``aal``/``dk``, Yeo-7 network for ``schaefer``), this groups by each region's dedicated ``Lobe`` field (frontal/ parietal/temporal/occipital/limbic/insula/subcortical/cerebellum/..., see :class:`~lqtpy.atlases.RegionMeta`). ``aal`` and ``dk`` define a lobe for every region; ``schaefer`` currently does not. Raises :class:`~lqtpy.errors.NoLobeMappingError` if the atlas has no lobe mapping for any region.

network_rollup_for(lesion, atlas_key: 'str', *, threshold: 'float' = 0.5) -> "'list[dict]'"

Group-level rollup records for one lesion, one row per region group. "Network" means the atlas's region Group field, which differs per atlas: Yeo-7 functional networks for ``schaefer``, but hemispheres for ``aal`` and ``dk``. Check the atlas before labelling this output as functional networks; :func:`lqtpy.report.fragments.network_rollup_fragment` titles itself from the data for the same reason.

tract_proxy_overlap(lesion, *, threshold: 'float' = 0.5) -> "'list[dict]'"

Per-tract white-matter structural-overlap **proxy** -- NOT disconnection. This is the fraction of each white-matter tract's voxels the lesion touches. A small lesion can fully disconnect a tract while overlapping few of its voxels, so this is a coarse proxy for damage to a tract's *territory*, not streamline-level disconnection. For the real, streamline-level measure -- what fraction of a tract's actual reference streamlines the lesion severs -- see :func:`tract_disconnection`, which requires a locally-built index (:mod:`lqtpy.datasets`) that this function does not.

tract_disconnection(lesion, *, threshold: 'float' = 0.5, index_path: "'str | None'" = None) -> "'list[dict]'"

Per-tract **real** streamline-level disconnection. For each of the ~70 named tracts in the HCP-842 population tractography atlas, a streamline counts as disconnected if **any** of its points falls in a lesion voxel (whole-streamline, binary -- no partial credit, no minimum-overlap-length; equivalent to ``dipy.tracking.utils.target(..., include=True)`` on the reference streamlines). Percent disconnection per tract is (disconnected streamlines in that tract) / (that tract's fixed reference streamline count, from the atlas, not recomputed per lesion) x 100. This reimplements the per-tract disconnection measure described in Griffis JC, Metcalf NV, Corbetta M, Shulman GL, "Lesion Quantification Toolkit: A MATLAB software tool for estimating grey matter damage and white matter disconnections in patients with focal brain lesions," *NeuroImage: Clinical* 30:102639 (2021). This is a genuinely different measure from :func:`tract_proxy_overlap`: that function reports what fraction of a tract's *voxels* the lesion's footprint touches (a spatial proxy, computable with only the bundled atlas), while this function reports what fraction of a tract's actual reference *streamlines* the lesion severs (the real measure, but it requires the locally-built streamline index below -- there is no bundled fallback). A small, well-placed lesion can fully disconnect a tract while overlapping only a few of its voxels; ``tract_proxy_overlap`` under-reports that case, which is exactly why this function exists. Requires a locally-built disconnection index (see ``tools/build_discon_index.py`` and :mod:`lqtpy.datasets`) -- :class:`~lqtpy.errors.DataUnavailableError` is raised with build instructions if one hasn't been built (or ``index_path`` doesn't exist). ``threshold`` follows the same convention as every other function here (see the module docstring): the lesion is loaded and binarized via :func:`lqtpy.io.load_lesion` exactly like :func:`tract_proxy_overlap` does, then resampled (nearest-neighbour) onto the tract atlas's own grid. Parameters ---------- lesion : anything :func:`lqtpy.io.as_lesion_image` accepts. threshold : float, default 0.5. index_path : str, optional Explicit path to a built index ``.npz``, bypassing the cached default index resolved from ``LQTPY_DATA_HOME`` (:func:`lqtpy.datasets.get_discon_index_path`). Mainly for tests and for a host app managing multiple index builds; loaded fresh each call (not cached) when given explicitly. Returns ------- list[dict] One record per tract, sorted by tract short code (deterministic order), with keys ``tract`` (short code, the stable identifier), ``name`` (corrected human-readable display name -- see :func:`lqtpy.datasets.get_tract_display_names`), ``n_streamlines`` (the tract's fixed reference count), ``n_disconnected``, and ``percent_disconnected``. Tracts with 0% are included, not dropped. Raises ------ lqtpy.errors.InvalidLesionError Empty lesion after thresholding (matches :func:`lesion_stats` / every other function here). lqtpy.errors.DataUnavailableError No disconnection index has been built locally.

list_atlases() -> 'list[str]'

Every atlas key: bundled, host-registered, and plugin-provided.

load_atlas(key: 'str') -> 'Atlas'

register_atlas(key: 'str', name: 'str', img, labels, *, overwrite: 'bool' = False, tier: 'str' = 'extra', source: 'str' = 'host', license: 'str' = '', citation: 'str' = '') -> 'None'

Register a host-supplied atlas. Once registered it works through :func:`load_atlas`, :func:`list_atlases`, and every function in :mod:`lqtpy.api`, exactly like a bundled atlas. ``img`` is anything :func:`lqtpy.io.as_lesion_image` accepts (a path, a nibabel image, or an ``(array, affine)`` tuple) -- an integer label volume, despite the name; the validation ``as_lesion_image`` does (3D, finite/non-singular affine, numeric dtype) applies equally to a label volume. ``labels`` maps an integer label id to a region name, or to a RegionMeta-compatible value (a :class:`RegionMeta`, a ``(RegionName, Group)`` pair, or a mapping/object with ``RegionName``/``Group`` and optionally any schema-v2 field). Registering an existing key without ``overwrite=True`` raises ``ValueError``. An unusable label volume (negative ids, non-integer values) raises :class:`~lqtpy.errors.InvalidAtlasError`.

preload(keys: "'list[str] | None'" = None) -> 'None'

Build (and cache) every atlas's label volume + per-label voxel counts up front. Call this once from FastAPI startup so the first request that needs an atlas doesn't pay the (one-time) load cost. Defaults to every *core* atlas plus host-registered ones (plugin atlases load on first use, since some fetch data). Also preloads the tract proxy index, the QC brain mask, the tissue distance maps, the border-zone map, the key-structure distance maps, and, if one has been built locally, the per-tract disconnection index -- a no-op, not an error, when it hasn't.

lqtpy.qc

Quality control for drawn lesion masks.

check(lesion, *, threshold: 'float' = 0.5, expected_side: "'str | None'" = None, mni: 'bool' = True, **options) -> "'list[Flag]'"

Run every QC check; returns flags sorted by severity (errors first). ``lesion``: anything :func:`lqtpy.prepare` accepts. ``expected_side``: "left"/"right" if the caller knows the clinical side. ``mni=False`` skips the brain-mask checks (for masks not meant to be in MNI space). ``options`` override :data:`DEFAULTS`.

clusters(lesion, *, merge_gaps: 'bool' = True) -> 'dict'

Lesion clusters: connected components, with gap-drawn slabs merged. Returns ``{"labels", "offset", "sizes", "merged_from", "gap_plane"}``: ``labels`` is an int32 array over the lesion's padded bounding box (1 = largest cluster), ``merged_from[i]`` lists the raw component ids joined into cluster ``i + 1``. Merging only happens when :func:`gap_evidence` finds a sparse-slice pattern and ``merge_gaps`` is true; then components within ``gap_max_mm`` of each other along the gap axis whose in-plane footprints overlap are joined.

repair_gaps(lesion, *, axis: "'int | None'" = None, max_gap_mm: "'float | None'" = None, threshold: 'float' = 0.5)

Fill sparse-slice gaps by shape-based interpolation. Opt-in only. Along the gap axis (from :func:`gap_evidence`, or ``axis`` = 0/1/2 on the lesion grid), the core slice of each drawn slab (a local maximum of the per-slice area) is a key slice; the slices between two neighbouring cores are filled by interpolating the cores' signed distance maps (shape-based interpolation). Existing voxels are always kept (the result is a superset of the input). The lesion's outermost tips beyond the first and last drawn slices are unknown and left alone. Returns ``(repaired_img, report)``; ``report`` says which plane was used, how many slices were interpolated and how much was added. When no gaps are found it returns an unchanged copy and says so.

clean(lesion, *, specks: 'bool' = True, edge: 'bool' = True, threshold: 'float' = 0.5, **options)

Remove image-edge artefacts and/or specks. Opt-in only. Returns ``(clean_img, report)`` with a *new* binary image; the input is never modified. ``report`` lists what was removed.

check_folder(folder, *, threshold: 'float' = 0.5, recursive: 'bool' = False, expected_sides: "'dict | None'" = None) -> "'list[dict]'"

Run :func:`check` on every lesion file in ``folder``. One record per file: ``file`` (path), ``name``, ``worst`` (ok / info / warn / error), ``flags`` (list of flag dicts), ``volume_mm3`` and ``error`` (a message when the file couldn't be read, else None). ``expected_sides`` maps names to "left"/"right" for the flip check.

clean_folder(src, dst, *, specks: 'bool' = True, edge: 'bool' = True, threshold: 'float' = 0.5, only_flagged: 'bool' = True) -> "'list[dict]'"

Write cleaned copies (:func:`clean`) of every lesion file in ``src`` into ``dst``. Never overwrites: ``dst`` must differ from ``src``, and a file that already exists in ``dst`` is skipped. With ``only_flagged`` (default), files with nothing to remove are not copied. Returns one record per file: ``file``, ``out`` (written path or None), ``status`` (written / nothing to remove / exists / failed) and the clean report.

lqtpy.tissue

Tissue composition and location classes (cortical, periventricular, ...).

composition(lesion, threshold: 'float' = 0.5) -> 'dict'

Percent of the lesion in each tissue class (they sum to 100): ``cortex, white_matter, deep_grey, ventricles, cerebellum, brainstem, csf, outside``.

locate(lesion, *, threshold: 'float' = 0.5, contact_mm: 'float' = 3.0, merge_gaps: 'bool' = True) -> 'dict'

Tissue composition of the whole lesion and a location class for each separate part (gap-aware parts, the same ones the description numbers). Returns ``{"composition", "class", "contact_mm", "parts", "counts"}``; each part has ``id, voxels, volume_mm3, class, tissue_class`` (the whole-lesion style class of that part), ``composition, dist_ventricle_mm, dist_cortex_mm, reaches_ventricle, reaches_cortex, max_axial_mm`` (the largest extent across an axial plane).

lqtpy.watershed

Border-zone ("watershed") locations between arterial territories.

border_zones(lesion, *, threshold: 'float' = 0.5, parts: 'bool' = True) -> 'dict'

Share of the lesion in each border zone. Returns ``{"zones": [{"id", "hemisphere", "kind", "name", "label", "pct_of_lesion"}], "pct_in_border_zones", "fits": bool, "kind": "cortical" | "internal" | "mixed" | None, "n_parts_internal", "n_parts"}``. ``fits`` is true when at least half the lesion lies in border zones, or when three or more separate parts lie mostly in the internal zone (the "chain" pattern).

lqtpy.structures

Key structures: distance from the lesion, and tract load at cross-sections.

distances(lesion, *, threshold: 'float' = 0.5, names=None) -> "'list[dict]'"

Shortest distance from the lesion to each key structure. Records: ``Structure, Hemisphere, DistanceMM`` (0 = the lesion reaches it; capped at 63.75), ``Reaches`` (bool). Sorted nearest first.

cross_section_load(lesion, *, threshold: 'float' = 0.5, min_overlap_pct: 'float' = 0.0) -> "'list[dict]'"

Tract damage at cross-sections, for every tract the lesion touches. Records: ``Tract, Hemi, PercentOverlap`` (voxel overlap, as :func:`lqtpy.tracts.tract_overlap`), ``MaxCrossSectionLoad`` (largest share of one 1 mm cross-section covered), ``BottleneckLoad`` (share of the narrowest cross-section covered), ``BottleneckAreaMM2``. Sorted by max cross-section load.

lqtpy.mirror

The lesion's mirror image in the other hemisphere.

mirror(lesion, *, threshold: 'float' = 0.5) -> 'nib.Nifti1Image'

The lesion reflected across the midline plane x = 0 (world mm).

homologue(lesion, *, threshold: 'float' = 0.5, atlas: 'str' = 'dk', top: 'int' = 6) -> 'dict'

Regions covered by the lesion's mirror image, and its symmetry. Returns ``{"regions": [{"name", "hemisphere", "pct_of_mirror", "function"}], "self_overlap_pct", "side"}``. ``side`` is the hemisphere the mirror image lies in ("right" for a left lesion).

lqtpy.native

Native-space masks: warp to MNI, and check quality where gaps are clearest.

warp_to_mni(native, transform, *, threshold: 'float' = 0.5, reference=None, order: 'int' = 1) -> 'nib.Nifti1Image'

Resample a native-space mask into MNI space (FSL MNI152 1 mm grid by default, or ``reference``'s grid). Linear interpolation then re-thresholding at 0.5, the way registration pipelines warp masks. Returns a uint8 image.

native_qc(native, *, threshold: 'float' = 0.5) -> "'list'"

The drawing checks run on the native mask, messages prefixed so a reader knows where they came from.

lqtpy.formats

Lesion file formats beyond NIfTI.

load_image(path: 'str')

Load any supported lesion file as a nibabel image.

read_nrrd(path: 'str') -> 'nib.Nifti1Image'

Read a 3-D NRRD file (``.nrrd`` with attached data, or ``.nhdr`` with a detached data file) into a RAS nibabel image.

write_nrrd(path: 'str', img_or_data, affine=None, *, encoding: 'str' = 'gzip') -> 'str'

Write a 3-D image as NRRD (LPS space, the common convention). Used by tests and for exporting masks to 3D Slicer.

read_dicom_seg(path: 'str', segments=None) -> 'nib.Nifti1Image'

Read a DICOM Segmentation object; all segments (or the listed segment numbers) are combined into one binary mask in RAS space. Needs ``highdicom`` (``pip install 'lqtpy[formats]'``). lqtpy.cohort

Cohort-level checks and statistics for group runs.

find_duplicates(sigs: "'list[Signature]'", *, min_dice: 'float' = 0.95, max_com_mm: 'float' = 5.0, max_volume_diff: 'float' = 0.1) -> "'list[dict]'"

Pairs of identical or near-identical masks. Identical: same voxels on the reference grid. Near-identical: centres within ``max_com_mm``, volumes within ``max_volume_diff``, and a Dice overlap of at least ``min_dice`` on a 2 mm grid.

find_outliers(subjects: "'list[dict]'", *, z_limit: 'float' = 3.5, min_n: 'int' = 10) -> "'dict[str, list]'"

``{name: [{"feature", "value", "z", "message"}]}`` for subjects far from the group (robust z-scores on log volume and on the distance of the centre of mass from the group's median centre). Needs ``min_n`` subjects; returns ``{}`` otherwise.

compare(per_subject: "'list[list[dict] | None]'", groups: "'list[str | None]'", a: 'str', b: 'str', key: 'str', value: 'str') -> "'list[dict]'"

Region-by-region comparison of two groups. ``per_subject[i]`` is subject i's records (e.g. its region table), ``groups[i]`` its group label. Subjects in neither group are ignored. Rows: ``Name, NAffectedA, NA, PctAffectedA, MeanA, NAffectedB, NB, PctAffectedB, MeanB, DiffMean, PFisher, QFisher, PMannWhitney, QMannWhitney``; means include unaffected subjects as 0. Sorted by the Mann-Whitney p.

lqtpy.registry

Plugin registry: core and extra *measures* (and extra atlases).

MeasureSpec(name: 'str', label: 'str', compute: 'Callable', fields: "'tuple[Field, ...]'" = (), tier: 'str' = 'extra', version: 'str' = '1', description: 'str' = '', interpret: "'Callable | None'" = None, min_voxels: 'int' = 0, requires: "'tuple[str, ...]'" = (), source: 'str' = 'builtin')

One output value of a measure.

Descriptor(measure: 'str', text: 'str', level: 'str' = '', detail: 'str' = '') -> None

A word-level interpretation of one or more measure values. ``text`` is the phrase a report shows ("compact, roughly round"); ``measure`` names the source measure; ``level`` is a short machine key ("compact") for tests and styling; ``detail`` explains the basis ("sphericity 0.82: top 20% of reference lesions").

list_measures(tier: "'str | None'" = None, *, available_only: 'bool' = True) -> "'list[MeasureSpec]'"

Registered measures, core first. ``tier`` filters to "core"/"extra". With ``available_only`` (default), measures whose ``requires`` are missing are left out (see :func:`unavailable_measures`).

register_measure(spec: 'MeasureSpec', *, overwrite: 'bool' = False) -> 'None'

Register a measure. Raises ``ValueError`` on a duplicate name unless ``overwrite=True``.

lqtpy.datasets

Data-home management for locally-built lqtpy datasets.

fetch_suit(base_url: 'str' = 'https://raw.githubusercontent.com/DiedrichsenLab/cerebellar_atlases/master/Diedrichsen_2009/', *, force: 'bool' = False) -> 'str'

Download the cerebellar lobule atlas (Diedrichsen et al. 2009, MNI space, 28 lobules + 6 deep nuclei; from the DiedrichsenLab ``cerebellar_atlases`` repository) into ``<data home>/suit``. After this, ``atlases=[..., "suit"]`` works. Returns the folder. The atlas is academic data: cite Diedrichsen J, et al. NeuroImage 46(1):39-46, 2009, and check the repository's terms. The files' SHA-256 digests are written to ``SHA256SUMS`` beside them.

get_data_home() -> 'str'

Root directory for locally-built lqtpy data. Resolution order: the ``LQTPY_DATA_HOME`` environment variable if set, else a sensible per-user cache directory (``%LOCALAPPDATA%\lqtpy`` on Windows, ``$XDG_CACHE_HOME/lqtpy`` or ``~/.cache/lqtpy`` elsewhere). Never creates the directory -- this is a path computation only, so importing/calling this at any time (including import time) has no filesystem side effect. Callers create it (or a parent of it) only when they're about to actually write something (see ``save_index`` usage in ``tools/build_discon_index.py``).

lqtpy.watch

Watch a folder: new or changed masks are analysed and the group report is rebuilt (``lqtpy watch FOLDER -o OUT``).

watch(folder: 'str', out_dir: 'str', *, interval: 'float' = 10.0, max_cycles: "'int | None'" = None, on_run=None, **group_kwargs) -> 'None'

Rebuild the group report whenever the folder's masks change. ``group_kwargs`` go to :func:`lqtpy.analyze_group` (``plots`` defaults to True, ``incremental`` is always on). ``max_cycles`` stops after that many polls (for tests); ``on_run(result)`` is called after each rebuild.
